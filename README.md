# CAPSTONE-PROJECT-<br>
💰 Money Manager App<br>
📌 Project Overview<br>

  
The Money Manager App is a web-based personal finance management application developed using HTML, CSS, and JavaScript.
It helps users track income and expenses, categorize transactions, and view financial summaries in a clean and user-friendly interface.
<br>

The application follows Object-Oriented Programming (OOP) principles and uses localStorage to persist data.
<br>
🎯 Objectives<br>
Track daily income and expenses<br>
Categorize transactions for better financial analysis
Display financial summaries (Income, Expense, Balance)
Provide a clean, responsive, and easy-to-use UI
Implement full CRUD operations using JavaScript<br> 


🛠️ Technologies Used
HTML5 – Semantic structure and layout<br>
CSS3 – Styling, layout, and responsive design<br>
JavaScript  – Application logic and OOP<br>
LocalStorage – Data persistence in the browser<br>


✨ Features<br>
🔹 Core Features
Add income and expense transactions
Auto-filled date with edit option
Category and sub-category selection
Optional transaction description
Vertical card-based transaction layout
Edit and delete transactions
Financial summary display:
Total Income
Total Expenses
Net Balance

<br>
Transactions remain available after page reload 
<br>
🎨 UI Presentation
Clean and minimal dashboard design
Vertical “table-box” transaction cards
Color-coded income and expense entries
Responsive layout for desktop and mobile devices
Modal popup form for adding transactions
